# Práctica UF2: Pilotes Saltarines

## 📌 Objetivo
Crear una animación con 25 pelotas de colores aleatorios que reboten en los bordes del canvas y entre ellas.

## 🛠️ Estructura del Proyecto
- **index.html**: Contiene la estructura básica y enlaza los recursos.
- **style.css**: Estilos para el canvas y título transparente.
- **main.js**: Lógica principal de la animación.
- **pilota.js**: Clase `Pilota` con la lógica de cada pelota.
